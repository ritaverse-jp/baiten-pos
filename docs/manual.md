# 売店レジ 使い方ガイド

スマートフォン・タブレットで注文の受付から精算までを行い、売上を自動でスプレッドシートに記録するアプリです。

**アプリのURL** … <https://ritaverse-jp.github.io/baiten-pos/>

| このガイドの読み方 | |
| --- | --- |
| はじめて使う方 | 「1. 最初の準備」→「2. 会計のしかた」 |
| 会計担当の方 | 「2. 会計のしかた」だけで日々の業務ができます |
| 管理者の方 | 「3. 商品・カテゴリの登録」「4. 履歴と取消」「6. 困ったときは」 |

---

## 1. 最初の準備（端末ごとに1回だけ）

新しいスマホ・タブレットで使い始めるときの手順です。**レジとして使う端末ごとに必要**です。

### 1-1. ホーム画面に追加する

1. **Safari**（iPhone・iPad）または **Chrome**（Android）で上記のURLを開く
2. 共有ボタン（□に↑のマーク）→ **「ホーム画面に追加」**
3. ホーム画面にできたアイコンから起動する

> **なぜ必要？** ホーム画面から起動すると、電波が届かない場所でもアプリが立ち上がります。ブラウザのタブから使うより安定します。

### 1-2. 端末を登録する

1. アプリを起動し、画面右上の **「設定」** を押す
2. **接続先URL** を入力して保存する（管理者から共有されたURLを貼り付けてください）
   - 保存すると自動で接続を確認し、結果が表示されます
3. **端末名**（例：「レジ1」）と **暗証番号（PIN）** を入力して **「この端末を登録」**
   - PINは管理者から聞いてください
4. 「端末コード」が自動で割り当てられれば完了です（A、B、C…）

> **端末コードとは？** 複数台で同時に会計しても、売上の番号が重ならないようにするための記号です。アプリが自動で決めるので、こちらで指定する必要はありません。

準備はこれで終わりです。以降、この端末では設定画面を開く必要はありません。

## 2. 会計のしかた

アプリを起動すると出る画面が「会計画面」です。ここだけで会計が完結します。

```
┌──────────────────────────┬─────────────┐
│ 売店レジ    [履歴][商品管理][設定]        │
├──────────────────────────┼─────────────┤
│ (フード) (ドリンク) (スイーツ)  │  伝票      │
├──────────────────────────┤ ─────────── │
│ ┌──────┐┌──────┐┌──────┐  │ ①からあげ串 │
│ │①からあげ ││②たこ焼き││③コーラ  │  │   500円 × 2 │
│ │  500円  ││  600円 ││  150円  │  │             │
│ └──────┘└──────┘└──────┘  │ 合計 1,000円│
│ [⌨ No.入力]                │ [ 精算へ ]  │
└──────────────────────────┴─────────────┘
```

> 画面を横向きにすると上の図のように左右に分かれ、縦向きにすると上下に分かれます。**どちらでも使えます。**

### 2-1. 商品を伝票に入れる

**方法1：商品ボタンを押す**（いちばん簡単）

上部のカテゴリを選び、商品ボタンを押すだけです。押すと右（または上）の伝票に入ります。

**方法2：番号で入れる**

1. **「No. 入力」** を押してテンキーを開く
2. 商品番号を入力して **「追加」**

> テンキーは、はじめは閉じています。番号入力を使わない方はそのままで構いません。

**同じ商品をもう1つ**

同じ商品ボタンをもう一度押すと、**個数が1つ増えます**（行は増えません）。

### 2-2. 個数を変える

伝票の各行にある **「−」「＋」** で増減します。

- 個数を0にすると、その行は削除されます（確認が出ます）
- 個数が1のときに「−」を押した場合も、確認のうえ削除されます

### 2-3. 割引をする

伝票の各行の **「割引」欄に円で入力**します。

> **割引は「1個あたり」に効きます。**
> 例：500円の商品を2個、割引50円 → (500 − 50) × 2 = **900円**
>
> 割引額は0円以上、商品の値段以下にしてください。

**同じ商品でも別々の割引をしたいとき**は、その行の **「行を分ける」** を押すと2行に分かれます。

### 2-4. 行を消す・全部消す

- 1行だけ消す … その行の **「✕ 削除」**
- 伝票を全部消す … **「伝票クリア」**

どちらも確認が出ます。

### 2-5. 精算する

1. **「精算へ」** を押す
2. お客様からお預かりした金額を入力
   - **1,000円 / 5,000円 / 10,000円 / ちょうど** のボタンが使えます
   - テンキーでの入力もできます
3. **おつり**が大きく表示されます
4. **「会計確定」** を押す（確認が出ます）

> **預かり金が足りないとき**は不足額が赤字で出て、確定ボタンは押せません。

確定すると伝票が空になり、次の会計に移れます。売上は自動でスプレッドシートに送られます。

## 3. 商品・カテゴリの登録（管理者）

会計画面の **「商品管理」** から行います。

> **インターネットに繋がっているときだけ編集できます。** 電波が無いときはボタンが押せません。複数の端末で内容がずれるのを防ぐためです。

### 3-1. カテゴリを先に作る

商品はカテゴリに属するので、**カテゴリを先に作ってください。**

商品管理 → **「カテゴリ管理」** → 「カテゴリを追加」

| 項目 | 説明 |
| --- | --- |
| カテゴリ名 | 20文字以内。「フード」「ドリンク」など |
| 表示順 | 会計画面でのタブの並び順（小さい順） |
| 表示色 | 16色から選べます。選ばなくても自動で色が付きます |

> **商品が1つでも入っているカテゴリは削除できません。** 先に商品を移動または削除してください。

### 3-2. 商品を登録する

商品管理 → **「商品を追加」**

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| No. | ○ | 1〜99。会計画面で①②③…と表示されます（21以降は数字） |
| 商品名 | ○ | 30文字以内 |
| 金額 | ○ | **税込**で入力してください |
| カテゴリ | ○ | 3-1で作ったものから選びます |
| 表示順 | | 未指定なら No. 順 |
| 販売状態 | ○ | 「無効」にすると会計画面に出なくなります |
| 写真 | | あとから追加・変更できます |

> **「無効」の使いどころ** … 品切れや期間限定の商品を、削除せずに一時的に隠せます。過去の売上には影響しません。

### 3-3. 商品の写真を登録する

商品の編集画面で **「写真を選ぶ」** を押し、撮影済みの写真またはその場で撮った写真を選びます。

- **サイズは自動で小さくなります。**大きな写真をそのまま選んで構いません
- 選ぶと「320×240px ・約30KB に縮小しました」のように表示されます
- 写真は **会計画面の商品ボタンの背景**と**伝票の小さな画像**に出ます
- 変更したいときは「写真を変更」、消したいときは「写真を削除」

> **写真は付けても付けなくても構いません。** 付けていない商品は文字だけのボタンになります。

### 3-4. 値段を変えたとき

**変更後の会計から新しい値段になります。**過去の売上が書き換わることはありません。

## 4. 履歴の確認と会計の取消

会計画面の **「履歴」** から、**その日の全端末ぶん**の会計を確認できます。

### 会計を取り消す

該当の会計の **「取消」** を押します（確認が出ます）。

- 取り消した会計には「取消済み」と表示されます
- スプレッドシートには**取消の記録が追加されます**（元の記録は残ります）。あとから経緯を追えるようにするためです

> **取り消せない場合があります**
>
> - **「未送信」と表示されている会計** … まだスプレッドシートに届いていないため取り消せません。電波の届く場所で少し待つと送信され、取り消せるようになります
> - **電波が無いとき** … 取消はインターネット接続が必要です

---

## 5. 電波が届かない場所での使用

**電波が無くても、会計はいつもどおりできます。**

- 商品の選択・割引・合計・おつりの計算・**会計確定まで、すべてオフラインで動きます**
- 確定した売上は端末の中に保存され、画面上部に **未送信の件数**が出ます
- **電波が戻ると自動でスプレッドシートに送られます**（何もしなくて構いません）

> **アプリを閉じても未送信のデータは消えません。**安心して閉じてください。

**オフラインのときにできないこと**

- 商品・カテゴリの登録や変更
- 会計の取消
- 他の端末の会計履歴の表示（自分の端末の分は表示されます）

---

## 6. 困ったときは

### 「オフライン」と表示される

電波の状況をご確認ください。会計は続けられます。設定画面の **「今すぐ同期」** で送信を試すこともできます。

### 「未送信」の件数が減らない

1. 電波の届く場所に移動する
2. 設定画面の **「今すぐ同期」** を押す
3. それでも減らない場合は、下の項目に該当していないか確認してください

### 暗証番号（PIN）の再入力を求められた

セキュリティのため、一定期間ごとに再確認しています。設定画面で **PIN を入力して再ログイン**してください。未送信のデータはそのまま残ります。

### 「この端末は無効化されています」と出た

管理者がこの端末の利用を停止した状態です。**未送信のデータがある場合は、設定画面から CSV としてダウンロードして管理者にお渡しください。**

### 「この端末の登録情報が見つかりません」と出た

登録をやり直せば復旧します。設定画面の **「登録をやり直す（リセット）」** を押してください。

> **未送信のデータがある場合は、先に CSV でダウンロードしてください。**
> 登録をやり直すと新しい端末コードになるため、それ以前の未送信データは送信できなくなります。画面にも確認が出ます。

### 写真が表示されない

- **他の端末で登録した写真**は、はじめの数秒だけ表示されないことがあります。取得が終わると自動的に出ます
- **電波が無い状態で一度も取得していない写真**は表示されません。写真が出なくても、会計の操作は問題なくできます

### 最新の状態にならない・動きがおかしい

ホーム画面のアプリを一度完全に終了し、開き直してください。それでも直らない場合は、Safari／Chrome で直接URLを開いてみてください。

## 7. 管理者の方へ：やってはいけないこと

売上データはスプレッドシートに記録されます。**次の操作はデータの不整合を招くため、行わないでください。**

| してはいけないこと | 理由 |
| --- | --- |
| **`端末` タブの行を削除する** | その端末が使えなくなります。復旧には端末側での再登録が必要です |
| **`売上ログ` の行を書き換える・削除する** | 売上の集計が合わなくなります。取消は必ずアプリの「履歴」から行ってください |
| **`商品マスタ`・`カテゴリ` を直接編集する** | アプリ側の入力チェックを通らないため、表示が崩れることがあります。必ずアプリの「商品管理」から操作してください |
| PIN を関係者以外に伝える | 端末の登録に必要な情報です |

> 集計や閲覧のためにスプレッドシートを**見る**のは問題ありません。**書き換えない**でください。

## 付録：知っておくと便利なこと

**会計番号の見方**

```
20260803-A014
└─日付──┘ │└┴─ その端末の当日14件目
           └─ 端末コード（A、B、C…）
```

端末ごとに番号が分かれるため、複数台で同時に会計しても番号が重複しません。

**金額の扱い**

- すべて**税込・円単位**です。アプリ内で税計算は行いません
- 1円未満は発生しません

**保存できる未送信データの上限**

1,000件です。これを超えるほど溜まる前に、一度電波の届く場所で同期してください。
